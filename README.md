# Su Takibi

Günlük su tüketimini takip etmeye ve vücut kütle endeksini hesaplamaya yarayan JavaScript uygulaması.

## Çalıştırma

Projeyi herhangi bir statik sunucu ile açabilirsiniz. Örneğin:

```bash
python -m http.server 5500
```

Tarayıcıda `http://localhost:5500` adresini ziyaret edin.

## Özellikler

- Günlük su hedefini takip eder
- 250, 500 ve 750 ml seçenekleriyle hızlı ekleme yapar
- Özel miktar ekler ve son eklemeyi geri alır
- Verileri tarayıcıda saklar
- Boy ve kilo bilgisiyle VKİ hesaplar
